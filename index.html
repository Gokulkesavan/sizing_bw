Header details

Always included: UDP 8 B, Ethernet header 14 B, FCS 4 B, padding to a 64 B minimum frame. On-wire adds 20 B for preamble, start delimiter and inter-frame gap. SRTP adds the selected authentication tag and optional MKI; the MKI is ignored for plain RTP. BGP and plain L2/L3 routing add no packet bytes; for GRE, IPsec or MPLS enter the overhead as extra bytes.
